Features

News Categories: Users can select different news categories to list news articles related to that category.

News Details: When a user clicks on a news item, the full details are displayed on a separate page.

Save Functionality (Under Development): Users can save their favorite news articles and access them later.

Technologies Used

React Native: Used to build the core structure of the application.

React Navigation: Used to handle screen transitions and manage navigation.

API: An external news API is used to fetch news data.

React Hooks: Used within functional components to manage state and handle side effects.

AsyncStorage (Under Development): Will be used to store and manage user-saved news articles locally on the device.
